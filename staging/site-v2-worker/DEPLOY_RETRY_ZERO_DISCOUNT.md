# Repetição controlada do deploy

Este arquivo registra a repetição da publicação do staging após uma falha na etapa de envio do Worker.

A alteração funcional já foi validada no PR #78 e remove toda apresentação de desconto quando a configuração comercial estiver em 0%.

Este marcador não altera o código executado, as configurações comerciais, o catálogo, o checkout ou a produção pública.
